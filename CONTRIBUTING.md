# Contributing

Use Conventional Commits for every commit.

```text
<type>(<scope>): <summary>
```

Use `feat` for new behavior, `fix` for corrections, and `docs`, `test`, `ci`, or `chore` for maintenance. Add `!` or a `BREAKING CHANGE:` footer for breaking changes.

Semantic-release publishes from `main`. Do not create or push release tags manually.
